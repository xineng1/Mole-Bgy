# MolBench · 分子生物实验台

一个装在浏览器里的分子生物学工具箱。**离线、零依赖、无后端**：所有计算都在本地完成，序列不会上传到任何服务器，断网也能用，整个文件夹可以拷进 U 盘带去实验室。

---

## 一、如何运行

> 只想尽快用起来？看 [QUICKSTART.md](QUICKSTART.md) —— 按实验任务组织的操作指南（设计引物 / 亚克隆 / 核对测序 / 验证酶切）。

**方式一（最简单）**：双击 `index.html`，用任意现代浏览器（Chrome / Edge / Firefox / Safari）打开即可。

**方式二**：用 VS Code 的 Live Server 等本地服务器打开，效果相同。

无需 Node、无需安装任何包、无需联网。

**URL 直达面板**（可直接收藏或分享）：

| 链接 | 打开位置 |
| --- | --- |
| `index.html#overview` | 序列概览 |
| `index.html#seqops` | 序列操作 / ORF |
| `index.html#protein` | 蛋白 & 密码子 |
| `index.html#digest` | 酶切分析 & 虚拟凝胶 |
| `index.html#primer` | 引物 & PCR |
| `index.html#align` | 序列比对（含多序列比对） |
| `index.html#clone` | 虚拟克隆 |
| `index.html#calc` | 实验计算器 |
| `index.html#help` | 说明 / 算法出处 |

**三十秒上手**：打开页面 → 已经自动载入了一条 2791 bp 的示例质粒 → 点「酶切分析」看位点图谱与虚拟凝胶 → 点「引物 & PCR」看自动挑好的引物和推荐程序 → 换成自己的序列即可。

**键盘快捷键**：`Ctrl/⌘ + 1…9` 按顺序切换面板，`Ctrl/⌘ + Enter` 执行当前面板的主操作（查找 ORF / 分析蛋白 / 设计引物 / 开始比对 / 模拟连接）。

**支持的输入格式**：FASTA、裸序列、带行号文本，以及 **GenBank**（自动提取 `ORIGIN` 段）和 **EMBL**（自动提取 `SQ` 段）——注释部分不会被误当成碱基。

## 二、核心功能

### 1. 序列概览

- 长度、GC%、分子量、最长 ORF、ORF 数量、浓度换算
- **GC 含量滑动窗口曲线**：窗口与步长可调，用来找 GC 岛、AT 富集区、判断序列是否异常
- **序列条形码**：每个碱基一色铺成色带，一眼看出重复序列与组成突变
- **分子量与 OD₂₆₀ 定量**：单链 / 双链 / RNA / 蛋白分子量互算，OD 读数 → µg/mL → nM 一步到位

### 2. 序列操作 / ORF

- 反向互补、互补、反向、转录、逆转录，一键生成并复制
- 六框翻译（+1/+2/+3/−1/−2/−3），氨基酸按理化性质着色
- **ORF 查找**：六框扫描，ATG 起始 + 终止密码子结束，最小长度可调。**报告嵌套 ORF**——遇到 `M1…M2…终止子` 这种结构时，M2 起始的短 ORF 不会被吞掉；**环状序列额外扫描跨越首尾接缝的 ORF** 并标注「跨接缝」。负链 ORF 的区间坐标已统一映射回原序列，可直接拿去取序列。点「查看」展开蛋白与核酸序列

### 2.5 蛋白 & 密码子

- **蛋白理化性质**：从当前序列一键提取最长 ORF 的蛋白（或直接粘贴蛋白序列），输出 pI（EMBOSS pKa 二分求解）、GRAVY 疏水性、不稳定指数（Guruprasad DIWV，>40 判不稳定）、脂肪族指数、消光系数 ε₂₈₀（氧化/还原两口径）、pH 7 净电荷与 20 种残基组成表——不用再开 ExPASy ProtParam
- **密码子优化 / 反向翻译**：按 E. coli K12 高表达偏好密码子逐残基选码，回译校验一致后才显示；自动扫描优化产物中 51 种常用酶的切点，提醒哪些位点需要用同义密码子规避；产物可复制或直接载入为当前序列接着分析

### 3. 酶切分析 & 虚拟凝胶 ⭐

- 内置 **51 种**常用限制性内切酶，含简并位点（如 AvaI `C^YCGRG`）
- 支持**线性 / 环状（质粒）**两种拓扑，环状与线性的片段数相差 1，不会算错
- **跨接缝位点识别**：环状模式下能识别跨越序列首尾接缝的酶切位点（表中标「跨接缝」），这是质粒分析中容易漏算的一类位点
- 切点定位表给出识别序列、起点、精确切割位置与末端类型
- 快捷筛选：**单切点酶**（做克隆时挑酶神器）、零切点酶、常用 8 种、pUC19 MCS
- **位点线性图谱**：横轴为序列，切点按酶着色标出，下方叠加 ORF 轨道（正链上排 / 负链下排）；鼠标悬停切点可看酶名、识别序列与精确切点
- **质粒环形图谱**：环状序列另有一张圆形图谱——外圈为序列与 bp 刻度（12 点方向为第 1 位、顺时针），径向线段为酶切位点，内圈弧段为 ORF（正链在外、负链在内），中心显示名称/长度/GC/切点数
- **虚拟琼脂糖凝胶**：按 log₁₀(片段长度) 反比迁移绘制，带 DNA Ladder 泳道、片段大小标注、条带亮度按质量分配。片段跑出胶外或留在孔中会画成贴边淡带提醒换胶浓度。**未酶切的环状质粒按三种构象画出三条带**——SC 超螺旋（最快）、LIN 线性、OC 开环/切口（最慢），符合实际电泳所见。凝胶图可一键存 PNG 贴进实验记录
- **Motif / 模式搜索**：任意 IUPAC 简并模式（启动子 -10/-35 区、RBS、polyA 信号、Kozak 等）在序列上的全定位，支持双链与环状跨接缝，内置常用预设
- **双酶切兼容性速查**：任选两个酶，立刻看到各自切点数、末端形态、是否同尾互补、联合酶切片段长度——双酶切克隆选酶不再靠翻表

### 4. 引物 & PCR

- **自动引物设计**：指定目标区域与约束（长度 / Tm / GC% / 产物上限），自动在区域两端搜索候选并打分排序，点「使用」即可填入下方分析。评分综合 Tm 接近 60 °C、GC 接近 50%、发夹与自身二聚体的 ΔG₃₇、**模板内结合位点唯一性**（出现多次重罚），配对时扣除交叉二聚体与 3′ 端配对的自由能，并评估**结合位点周边的模板局部 GC**（过高有二级结构、过低易非特异）；设计不出结果时会根据模板整体 GC 给出针对性建议（如放宽 GC 上限 + 加 DMSO）
- 三种 Tm 算法并列：**最近邻法**（SantaLucia 1998 + Owczarzy 2004 盐校正，推荐）、GC% 经验式、Wallace 规则
- Na⁺ / Mg²⁺ / dNTP / 引物浓度全部可调，贴合真实 PCR 缓冲液条件
- **二级结构按 ΔG₃₇ 热力学评估**（而非"连续互补碱基数"这种粗略指标）：发夹按茎区最近邻自由能 + 环 initiation 罚值计算，二聚体枚举反平行配对求最优自由能，并单独标出最危险的 **3′ 端参与配对**
- 风险提示：发夹、自身二聚体、交叉二聚体、3′ 端互补、GC 夹、两引物 Tm 差
- PCR 产物大小与序列预测（在模板上定位引物结合位点）
- **定点突变引物（Q5® SDM 型）**：指定突变位置与类型（点突变 / 连续替换 / 插入 / 缺失），自动设计背对背引物——突变放在正向 5′ 端，退火区按最近邻 Tm 自动延长到达标；给出 KLD 处理流程与 PCR 程序建议，可一键填入引物输入框做完整评估
- **推荐 PCR 程序**：由 Tm 自动给出退火温度、延伸时间、循环数；两引物 Tm 偏低时自动改用 touchdown 方案

### 5. 实验计算器

| 计算器 | 用途 |
| --- | --- |
| 溶液稀释 | C₁V₁ = C₂V₂，任意三项求第四项 |
| 质量 ⇄ 摩尔 | mg / mmol 互算，% w/v 与摩尔浓度互算 |
| PCR 体系配制 | 输入母液浓度自动生成加样表 + Master Mix（按 N 管 + 余量），体积超限时报警 |
| 离心机换算 | rpm ⇄ ×g，带离心半径 |
| 菌浓估算 | OD₆₀₀ → cells/mL（大肠杆菌 / 酵母 / 芽孢杆菌） |

### 6. 序列比对

- **双序列全局比对**（Needleman-Wunsch，可调匹配 / 错配 / gap 罚分），用于核对测序结果与参考序列
- 输出一致度、比对得分、一致/错配/gap 计数，以及带坐标的三行比对视图（每 60 列一行，中缀 `|` 标出一致位点）
- 一键把当前序列填入 A / B，可交换两侧；自带含缺失与错配的演示对
- **多序列比对**：把 3 条以上序列（或多条 FASTA 记录）贴进 A 框即自动切换，用**中心星算法**（center-star）比对，
  输出序列条数、列数、完全保守列占比、两两一致度均值，并以「|」标出所有序列完全一致的列
- 超过 400 万矩阵单元（约 2000 × 2000）时拒绝执行并提示截短，避免卡死浏览器

### 7. 虚拟克隆

- 载体（按环状）与插入片段（按线性）各自选酶酶切，分别挑出骨架与插入片段
- **黏端兼容性判定**：从识别序列里 `^` 的位置推导末端形态（5′ 突出 / 3′ 突出 / 平端），
  按"同型 + 突出序列相同"判断能否连接
- 因此能识别**同尾酶**（BamHI×BglII、SalI×XhoI 产生的都是 5′-GATC / 5′-TCGA），
  也会正确拒绝 EcoRI×BamHI、5′ 突出×3′ 突出这类不兼容组合
- 不兼容时给出方向性提示（补平 / 加接头 / 换同尾酶）；兼容时输出重组序列、大小变化与 GC%，可一键载入为当前序列
- 对简并酶（如 AvaI `C^YCGRG`）的突出端会标注"无法判定"，不硬猜
- **连接反应用量计算**：按 插入:载体 摩尔比（660 g/mol/bp 折算）算出各需多少 ng，填入浓度后进一步给出各吸取多少 µL；可一键把上方选好的骨架/插入片段长度填进来

### 8. 导入 / 导出 / 历史

| 能力 | 说明 |
| --- | --- |
| 读取 | FASTA、裸序列、带行号文本、GenBank（取 `ORIGIN` 段 **并解析 `FEATURES` 注释**：CDS/gene/mRNA 的位置、链向、基因名与产物，支持 `complement` / `join` 与跨行 `translation`，可一键提取该区段序列）、EMBL（取 `SQ` 段） |
| 导出 FASTA | 当前序列存为 `.fasta` |
| 导出分析报告 | 把序列信息、分子量、ORF、酶切结果、引物与 PCR 程序一次性导出为 **Markdown**，可直接贴进实验记录 / Obsidian / 腾讯文档 |
| 导出凝胶图 | 虚拟凝胶存为 PNG |
| 历史记录 | 停止输入 2 秒后自动保存最近 10 条序列到**本机浏览器**（localStorage，不上传任何服务器），可一键切回；超过 100 kb 的序列不入库，配额不足时自动丢弃最旧的 |

## 三、创意点与实用价值

**① 它解决的是"每天都要算一遍"的事。**
分子生物学实验里最高频的动作不是高深分析，而是些琐碎换算：这段序列酶切后跑胶会是几条带？引物 Tm 多少度、退火设几度？25 µL 体系各加多少？OD 读数换算成多少 nM？这些事平时要么开好几个网页工具、要么手算，MolBench 把它们收进一个界面，离线就能用。

**② 「虚拟凝胶」把抽象数字变成图像。**
酶切片段表给出的是一串数字，而真实的实验判断发生在看胶的时候。MolBench 直接把片段长度画成模拟电泳图——几条带、大概在什么位置、哪条最亮、小片段会不会跑出胶外，一眼就有概念。这样在动手前就能判断"这个双酶切方案能不能分得开"，少跑一次废胶。这是本项目最有辨识度的部分。

**③ 参数不是抄来的黑箱，而是按文献实现并经过验证。**
最近邻 Tm 用的是 SantaLucia 1998 统一参数，盐校正用 Owczarzy 2004，Mg²⁺ 折算为等效 Na⁺；双链分子量按 A·T 对 617.41、G·C 对 618.39 Da 计算。这些都在 `README` 与页面「说明」里标注了出处，不是拍脑袋。

**④ 为教学演示而生。**
内置两条专门构造的示例序列：一条是含启动子 / RBS / 148 aa CDS / 多克隆位点 / GC 岛的环状质粒，一条是含 GC 岛的基因组片段。打开就有完整可读的结果，适合课堂演示、实验预习、以及给师弟师妹讲解酶切与引物设计。

**⑤ 面向实验台的真实细节。**
环状/线性切换、简并酶、单切点酶筛选、3′ 端二聚体、Master Mix 余量、片段跑出胶外提示……这些细节都是真正做过实验才会想到的，而不是通用工具网站的常见功能。

## 四、算法出处

| 项目 | 来源 |
| --- | --- |
| 遗传密码表 | NCBI translation table 1（标准） |
| 最近邻热力学参数 | SantaLucia, PNAS 1998, unified parameters |
| 盐校正 | Owczarzy et al., Biochemistry 2004 |
| Tm 计算式 | Tm = ΔH×1000 / (ΔS + R·ln(C_T/4)) − 273.15 |
| GC% 经验 Tm | Tm = 64.9 + 41×(n_GC − 16.4)/N |
| Wallace 规则 | Tm = 2(A+T) + 4(G+C)，仅适用于 < 14 nt |
| 核酸残基质量 | dA 313.21 / dC 289.18 / dG 329.21 / dT 304.20 Da |
| OD₂₆₀ 系数 | dsDNA 50、ssDNA 33、RNA 40 µg/mL per OD |
| 离心力 | RCF = 1.118×10⁻⁵ · r(cm) · rpm² |
| 等电点 pI | EMBOSS/Bjellqvist pKa + Henderson-Hasselbalch，二分求净电荷零点 |
| GRAVY 疏水性 | Kyte & Doolittle 1982 |
| 脂肪族指数 | Ikai 1980 |
| 不稳定指数 | Guruprasad et al. 1990（DIWV 二肽权重，10/L·Σ） |
| 消光系数 | Pace et al. 1995：ε₂₈₀ = 5500·W + 1490·Y（+125·C 全氧化） |
| 密码子优化 | E. coli K12 高表达偏好密码子表（Kazusa） |
| 连接用量 | 双链 DNA 按 660 g/mol/bp 折算 pmol |

> 虚拟凝胶的迁移距离为经验模型（d = a − b·log₁₀(bp)），仅用于判断片段相对位置与能否分开；实际迁移率还受 DNA 构象、电压、染料影响。

1. 翻译结果着色时 `<span>` 被换行从中间切断（每 60 aa 就有 20+ 处，导致标签永不闭合、颜色错乱）
2. 搜索过滤酶列表时，不在过滤结果中的已选酶被静默丢弃
3. 蛋白 / 未知序列下序列操作按钮未禁用，产出全是 `X` 的垃圾翻译
4. 环状序列跨接缝位点漏识别

**浏览器像素自检的用法**（这类"看不见画布"的验证很关键）：

```bash
chrome --headless=new --disable-gpu --allow-file-access-from-files \
  --virtual-time-budget=15000 --dump-dom tools/visual_check.html
```

它会输出一段 JSON，包含各画布的有色像素数、颜色数、凝胶条带的行分布等，可用于确认图形真的画出来了、条带位置符合预期（例如未酶切质粒的 SC/LIN/OC 三条带应落在 y ≈ 129 / 162 / 193）。

## 七、性能特征

用 `node tools/profile.js`（jsdom 中模拟真实操作，每项多轮采样取最小值）在 **120 kb 序列**下实测：

| 操作 | 首次 | 后续（缓存生效） |
| --- | --- | --- |
| 切到酶切面板 | ~196 ms | **60 ms** |
| 勾选一个酶后重绘 | ~125 ms | **70 ms** |
| 切换凝胶浓度后重绘 | ~93 ms | **46 ms** |
| 切到序列概览 | ~64 ms | **46 ms** |
| 自动引物设计（默认全长） | 121 ms | 121 ms |
| 输入 120 kb 序列 | 709 ms（其中 220 ms 是防抖） | — |

**关键设计：结果缓存。** `findORFs` 是 O(6n) 的六框扫描，120 kb 下单次约 45–60 ms，而概览、位点图谱、环形图谱、报告、ORF 面板共 5 处都要用。用 `seqId` 作缓存键后，**连续 3 轮切换面板只触发 1 次扫描**（未缓存时为 9 次以上）。分子量同理：一次 `baseCount` 算出单链 / 双链 / RNA 三个值，而不是对同一序列反复做 O(n) 统计。

**自适应防抖**：小于 50 kb 保持 220 ms 即时反馈；超过 50 kb 放宽到 500 ms，避免编辑大序列时每停顿一次就跑一次完整渲染。

**渲染成本隔离**：酶列表（51 个 checkbox）只在"选中集合被程序改动"或搜索关键字变化时重建，勾选单个酶、切换凝胶浓度、切面板都不再重建 DOM。

> 注：上表在 jsdom 中测得，其 DOM 操作比真实浏览器慢数倍，因此真实使用会比表中更快；这里用于**横向对比优化的相对收益**，而非绝对性能承诺。

## 八、已知边界

**算法模型层面的限制（诚实说明，不掩饰）**

- 简化碱基（R/Y/N 等）参与酶切匹配与翻译时按通配处理，结果可能不完整。
- 引物二级结构用**简化热力学模型**：只按连续完美配对累加最近邻自由能并叠加上环罚值，**不处理凸起、内部环与错配**。因此对"带错配但依然稳定"的结构会低估稳定性；风险阈值（发夹 < −3、二聚体 < −5 kcal/mol）已按此模型标定。用于正式实验前建议用 Primer3 / OligoAnalyzer 复核。
- 自动引物设计未做**跨外显子设计**（需要基因结构注释）；模板二级结构仅用结合位点周边的局部 GC 作为代理指标，未做折叠计算。
- 凝胶迁移距离是经验模型（d = a − b·log₁₀(bp)），仅用于判断片段相对位置与能否分开；质粒三构象的迁移系数同为经验值。
- **多序列比对用的是中心星算法**，不等价于 Clustal / MAFFT 那类迭代优化算法。它速度快、结果稳定，
  但序列长度差异很大时比对质量会下降；同一批序列的比对结果也不随输入顺序变化（中心选择是确定的）。
- 虚拟克隆目前覆盖**单插入片段的定点克隆**，不做多片段组装（Gibson / Golden Gate）、不模拟连接效率与方向性，
  也不检查读框是否对齐——连接成功的序列不等于表达正确的构建体。

**功能层面的空缺**

- 不做转化、筛选、测序验证等下游步骤的模拟。
- GenBank 解析 `join` 多段坐标，但不处理 CDS 的 `phase`（读框相位）与远程 `complement` 复合写法。
- 报告仅导出 Markdown，无 PDF / 图片格式。

以上均不影响现有功能的正确性；所有结果供学习与实验设计参考，关键实验请以试剂盒说明书与实测为准。
