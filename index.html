MolBench 是什么

一个装在浏览器里的分子生物学小工具箱。所有计算在本地完成，序列不会上传到任何服务器，断网也能用。整个程序就是一个文件夹，双击 index.html 即可运行，也可以拷进 U 盘带去实验室。

  • 序列概览：长度、GC%、组成、GC 窗口分布、序列条形码、分子量与 OD₂₆₀ 定量。
  • 序列操作：反向互补、转录、六框翻译、ORF 查找与导出。
  • 蛋白 & 密码子：蛋白理化性质一站式分析（pI、GRAVY、不稳定指数、脂肪族指数、消光系数、残基组成），以及按 E. coli 偏好密码子的反向翻译 / 密码子优化，并自动提示优化产物中新出现的酶切位点。
  • 酶切分析：51 种常用酶的切点定位、线性/环状酶切片段计算（含跨接缝位点）、位点线性图谱与虚拟凝胶电泳图；另有 Motif 模式搜索（IUPAC 简并，找启动子 / RBS / polyA）与双酶切兼容性速查。
  • 引物 & PCR：自动引物设计、三种 Tm 算法、GC 夹、发夹与二聚体风险、产物大小与推荐程序；支持 Q5® 型定点突变引物（点突变 / 插入 / 缺失）。
  • 实验计算器：稀释、质量-摩尔换算、PCR 体系配制、rpm⇄×g、菌浓估算。
  • 序列比对：双序列全局比对（Needleman-Wunsch）；贴入 3 条以上序列会自动切换为多序列比对（中心星算法，标出保守列）。
  • 虚拟克隆：载体与插入片段分别酶切 → 各选一段 → 检查黏端能否互补（含同尾酶判定）→ 得到重组序列；配套的连接反应用量计算直接按摩尔比给出 ng 与 µL。
  • 导入导出：FASTA / GenBank / EMBL 文件读取（GenBank 的 FEATURES 注释可解析并提取区段），导出 FASTA、分析报告（Markdown）、凝胶图（PNG）；最近用过的序列保存在本机浏览器中。

使用小贴士

  • 粘贴带行号或每行 60 碱基的 FASTA 都没问题，程序会自动清洗空白与数字。
  • 分析质粒时记得勾选「环状」，环状与线性的酶切片段数差 1。
  • 双酶切做克隆时，先看「单切点酶」筛选，能快速挑出不切断目的基因的酶。
  • 虚拟凝胶只是示意：超螺旋质粒实际跑得比线性快，开环最慢，图里未按构象区分。
  • 引物 Tm 以最近邻法为准；两引物 Tm 差 > 3 °C 时建议重新设计较短的一条。

自检与性能

核心算法与界面逻辑附带一整套断言测试，在项目目录执行（jsdom 相关测试需先把 NODE_PATH 指向已装 jsdom 的 node_modules）：

node tools/check.js   # 核心算法断言 270+ 项，全部通过才算交付
  • tools/check.js：FASTA/GenBank 解析、反向互补、翻译、GC/Tm、分子量、浓度换算、线性与环状酶切、简并酶、ORF 与 PCR、比对、蛋白理化性质、反向翻译、连接用量、突变引物、Motif、双酶切
  • tools/bug_hunt.js：核心层缺陷猎取——环状拓扑、负链坐标、极端输入、数值抽查、酶库自洽，以及新功能的随机对拍与穷举对拍
  • tools/dom_smoke.js / bug_hunt_ui.js：用 jsdom 真实加载页面，模拟点击与输入，捕捉运行时异常与 UI 状态不一致
  • tools/feature_audit.js：功能对账——导入导出、注释解析、历史记录、报告章节连续性、新功能入口与帮助页承诺一致性
  • tools/cross_validate.js：独立朴素实现对拍（酶切 / ORF / PCR / 翻译 / 引物约束 / 比对）
  • tools/profile.js：多轮采样性能剖析，定位耗时热点
  • tools/visual_check.html：真实浏览器内 canvas 像素自检（条带数量、图谱配色、构象带、localStorage 可用性）
